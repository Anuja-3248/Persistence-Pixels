# 🛡️ Persistence-Pixels | DisasterX

DisasterX is a pro-level disaster management application that uses real-time situational data and interactive training modules to provide emergency response coordination and crisis preparedness.

## 🚀 Features
- **Visual Emergency Briefing**: Real-time video-first context for ongoing disasters.
- **Survivor Protocols**: Structured "Before, During, After" safety guides.
- **Interactive Live Drills**: "Pause & Decide" simulations based on real-world protocols.
- **ShieldAI Coordinator**: Mock AI assistant for rapid information retrieval.

## 🤝 Project Structure
- `src/components/`: Resilience-focused UI elements (ScenarioCards, Chatbot).
- `src/pages/`: Core operational views (Dashboard, Map, SOS, Resources).

*Developed with focus on visual excellence and crisis resilience.*
